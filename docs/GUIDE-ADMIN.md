# Guide de l’espace administrateur

Adresse : **https://belavica.com/admin** — connexion avec `leona@belavica.com`.
Astuce iPhone : ouvrez la page dans Safari → *Partager* → **Sur l’écran d’accueil** pour l’avoir comme une application.

## Le principe des réservations

1. La cliente choisit sa prestation et un créneau libre → **demande en attente**. Le créneau est bloqué pour les autres.
2. Vous recevez un e-mail « Nouvelle demande ». Dans **Tableau de bord** :
   - **Accepter** → la cliente reçoit la confirmation (acompte, conditions d’annulation, lien pour gérer son rendez-vous) ;
   - **Refuser** → elle reçoit un message (vous pouvez ajouter un mot), le créneau se libère.
3. Pas d’acompte au lancement. Si vous souhaitez en demander un plus tard : *Paramètres* → cocher « Demander un acompte » (puis suivi dans chaque réservation, bloc *Suivi*).
4. Annulation par la cliente : possible via son lien. Si elle annule à moins de 48 h, la réservation est marquée « tardive » pour que vous le voyiez.

## Écrans

- **Tableau de bord** : demandes à valider, rendez-vous du jour et de la semaine, liste « À faire ».
- **Agenda** : vues jour / semaine / mois. Cliquez un rendez-vous pour l’ouvrir. Gris rayé = bloqué ou congé.
- **Réservations** : recherche (nom, e-mail, téléphone, référence BV-…, prestation) et filtre par statut.
  Dans une réservation : modifier date/heure/durée/prix, marquer terminé ou absente, note interne, renvoyer la confirmation, annuler.
- **+ Rendez-vous** : ajout manuel (rendez-vous pris par Instagram ou téléphone). Il est directement confirmé.
  Les horaires d’ouverture ne s’appliquent pas, mais un chevauchement reste impossible.
- **Clientes** : coordonnées, historique, notes internes privées, suppression des données (RGPD).
- **Prestations** : prix, durée, textes, visibilité, ordre ; formules (ex. Renforcement / Extension) ; options (French).
  « Supprimer » retire la prestation du site sans effacer l’historique.
  Les **formations 10 h / 20 h** sont en mode « sur demande » : la cliente envoie ses disponibilités ; ouvrez la demande, planifiez la première séance, puis ajoutez les suivantes avec **+ Rendez-vous**.
- **Disponibilités** : horaires (plusieurs plages par jour possibles), pauses, congés, créneaux bloqués, et règles :
  intervalle des créneaux, temps tampon entre deux rendez-vous, délai minimum avant réservation, nombre de jours réservables à l’avance.
- **Site** : tous les textes, la photo « À propos », le compte Instagram, les mentions légales, et la galerie (ajout de photos depuis le téléphone).
- **Paramètres** : e-mail de notification, montant de l’acompte, délai d’annulation, rappels automatiques, durée de conservation des données, e-mail de test, journal des e-mails.

## Bon à savoir

- Si un e-mail échoue, le site ne le cache jamais : message ⚠ dans l’admin et détail dans *Paramètres → Journal des e-mails*.
- Les notes internes ne sont jamais visibles par les clientes. N’y indiquez que l’utile à la prestation.
- Chaque modification de textes, prix ou horaires est visible immédiatement sur le site.
